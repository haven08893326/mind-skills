# Contributing to Mind Skills

Thank you for helping improve this bilingual skill package.

## Before contributing

- Keep English and Chinese user experiences aligned.
- Preserve the original Chinese framework unless a change is intentional and documented.
- Use natural English trigger phrases and include realistic example prompts.
- Keep the toolkit non-clinical and maintain the safety boundaries.
- Do not include private, identifying, or clinically sensitive case details.

## Suggested contributions

- Improve English wording and trigger coverage.
- Add Chinese-English terminology mappings.
- Improve installation instructions.
- Report broken links, packaging problems, or unclear behavior.
- Add examples that help users understand when to use each module.

## Pull requests

Please describe what changed, why it helps users, and whether both Chinese and English behavior were checked. Keep pull requests focused and avoid unrelated rewrites.

## Safety

Do not submit content that presents the toolkit as a medical diagnosis, emergency service, or replacement for qualified professional care.
